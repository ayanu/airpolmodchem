isa.zz.2.ttR Documentation

Altitude to pressure for international standard atmosphere

Description

Estimates the temperature for a given altitude above sea level and international standard atmospheric conditions.

Usage

isa.zz.2.tt(zz = 0)

Arguments

zz

(numeric) altitude above sea level in [m]

Value

(numeric) temperature [K]

Author(s)

stephan.henne@empa.ch
