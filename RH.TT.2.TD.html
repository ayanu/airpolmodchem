RH.TT.2.TDR Documentation

Calculate dew point temperature of an air parcel

Description

Calculate dew point temperature of an air parcel (K) from the air parcel's relatve humidity (%) and its ambient temperature (K or °C).

Usage

RH.TT.2.TD(rh, tt)

Arguments

rh

relative humidity (%)

tt

ambient temperature (K if >150, °C if <150)

Value

dew point temperature (K)

Author(s)

Stephan Henne

Examples

## 
print(RH_TT_2_TD(100, 20))
