# AirPolModChem

\## Overview

The R package AirPolModChem provides a collection of useful functions
and simple toy models as discussed during the ETH Zürich lecture Air
Pollution Modeling and Chemistry in HS2026.

## Installation

Direct installation from github can be done after installing R packages
`devtools` or `remotes`:

    install.packages("remotes")

Then installation can be started using

    library(remotes)
    install_github("ayanu/airpolmodchem")

## Usage

The package contains several functions that are used for exercises in
the lecture. For details refer to the function
[reference](https://ayanu.github.io/airpolmodchem/reference/index.html).

## Getting help

Please refer to the package
[documentation](https://ayanu.github.io/airpolmodchem) first. If that
does not solve your questions, contact the developer directly.
