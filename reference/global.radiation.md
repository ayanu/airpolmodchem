# Calculate clear sky global radiation at time and location

Using simplified equation based on soloar elevation angle as given in
Stull 1982

## Usage

``` r
global.radiation(dtm = 0, lon = 0, lat = 0)
```

## Arguments

- dtm:

  date/time as chron object

- lon:

  longitude in degree east

- lat:

  latitude in degree north

## Value

global radidation in units W m-2
