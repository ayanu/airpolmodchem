# Pressure to altitude for international standard atmosphere

Estimates the altitude above sea level for a given pressure level and
international standard atmospheric conditions.

## Usage

``` r
isa.pp.2.zz(pp = 1013.25)
```

## Arguments

- pp:

  (numeric) pressure level in (hPa) !

## Value

(numeric) altitude above sea level in (m)

## References

Compare http://en.wikipedia.org/wiki/International\\Standard\\Atmosphere
and Etling, D.: 1996. Theoretische Meteorologie.
