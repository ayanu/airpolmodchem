# Calculate solar azimth angle

The solar azimuth angle is the azimuth (horizontal angle with respect to
north) of the Sun's position. This horizontal coordinate defines the
Sun's relative direction along the local horizon, whereas the solar
zenith angle (or its complementary angle solar elevation) defines the
Sun's apparent altitude (see 'solar.zenith.angle).

## Usage

``` r
solar.azimuth.angle(tm, lon = 0, lat = 0)
```

## Arguments

- tm:

  date/time object (chron)

- lon:

  Longitude in degrees east

- lat:

  Latitude in degrees north

## Value

Solar azimuth angle in radians
