# Calculate solar elevation angle

The solar elevation angle (or its complementary angle solar zenith
'solar.zenith.angle) defines the Sun's apparent altitude. It is the
angle between the sun's rays and local horizon. Maximum value at solar
noon. Night-time values smaller 0.

## Usage

``` r
solar.elevation.angle(tm = 0, lon = 0, lat = 0)
```

## Arguments

- tm:

  date/time object (chron)

- lon:

  Longitude in degrees east

- lat:

  Latitude in degrees north

## Value

Solar elevation angle in radians
