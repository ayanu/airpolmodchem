# Physical constants

Constants often needed for atmospheric calculations.

## Usage

``` r
R.star
R.air
R.h2o
k.b
N.A
mu.air
mu.h2o
T.0
PP.0
F.0
g.0
```

## Details

|        |                                                         |         |
|--------|---------------------------------------------------------|---------|
| Symbol | Description                                             | Units   |
| R.star | Universal gas constant                                  | J/K/mol |
| R.air  | Specific gas constant for dry air                       | J/kg/K  |
| R.h2o  | Specific gas constant for water vapor                   | J/kg/K  |
| k.b    | Boltzmann constant                                      | J/K     |
| N.A    | Avogardo number (number of atoms/molecules in one mole) | 1/mol   |
| mu.air | Molecular weight of dry air                             | g/mol   |
| mu.h2o | Molecular weidht of water                               | g/mol   |
| T.0    | Freezing point of water                                 | K       |
| PP.0   | Standard ambient sea level pressure                     | hPa     |
| F.0    | Solar constant                                          | W/m2    |
| g.0    | Average gravity of Earth                                | m/s2    |
