chron.2.stringR Documentation

Formats a chron object to character

Description

Converts a chron object to a character representation. The same formatting specifiers are used as format.POSIXlt

Usage

chron.2.string(dtm, form = "%Y-%m-%d %H:%M:%S", tz = "GMT")

Arguments

dtm

chron object

form

format string, see format.POSIXlt for details

tz

(character) giving name of time zone, see as.POSIXlt

Value

formatted date/time string
